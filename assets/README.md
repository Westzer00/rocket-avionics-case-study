# 공개 프로젝트 사진

이 폴더에는 사용자가 제공한 GOAT 로켓 팀 프로젝트 사진에서 공개에 적합한 장면을 골라 **웹용 사진**로 저장했습니다.

| 파일 | 설명 |
|---|---|
| `photos/rocket-assembly.webp` | 로켓 실물·조립 상태 |
| `photos/avionics-hardware.webp` | 비행전자 모듈 조립 모습 |
| `photos/parachute-deployment.webp` | 실제 비행 중 낙하산 분리·사출 장면 |
| `photos/parachute-in-flight.webp` | 새로 제공된 비행시험 사진의 낙하산 전개·하강 장면 |

각 사진은 팀 공동 제작·시험 과정을 보여주는 자료이며, 개인 단독 제작을 증명하는 것으로 사용하지 않습니다. 팀원 얼굴이나 명함, 회사 비공개 정보를 식별할 수 있는 사진은 별도로 게시하지 않습니다.
